> Антивирус может среагировать на WinDivert.  
> Этот инструмент перехватывает и фильтрует трафик, поэтому он необходим для работы zapret.
> WinDivert применяется как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусные продукты классифицируют файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляют их либо отправляют в карантин. Название такого обнаружения обязательно содержит `WinDivert` или выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Можно добавить папку с запретом в исключения антивируса или отключить обнаружение PUA — потенциально нежелательных приложений. Например, в Касперском за это отвечает настройка «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы умеете аккуратно настраивать исключения, рекомендуется использовать именно их. Если не уверены в своих действиях, лучше отключить обнаружение PUA.

## ⚙️Использование

1. Настройте Безопасный DNS (Secure DNS)
    * Chrome: включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * Firefox: включите «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную укажите URL. Например, подойдёт `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах системы — воспользуйтесь [этой инструкцией](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется именно этот способ
    * Владельцам роутеров Keenetic необходимо включить параметр «Транзит запросов». Если он отключён, настройка и использование Secure DNS на компьютере могут работать некорректно

2. Откройте [страницу актуального релиза](https://github.com/townfiscalspout/zapret-discord-youtube/releases/latest) и загрузите архив в формате zip или rar

3. Откройте свойства загруженного архива и отметьте пункт «Разблокировать». При использовании 7-Zip или PeaZip выполнять этот шаг не требуется

4. Извлеките файлы в каталог, путь к которому не содержит кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы определить рабочую стратегию: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Чтобы добавить стратегию в автозапуск: **`service.bat`** → `Install Service` → *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии

  Ручной режим удобен для проверки стратегий. Их работоспособность зависит от множества условий, поэтому **перебирайте разные варианты — ALT, FAKE и другие, — пока не найдёте подходящее решение**

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные инструменты:
  - <ins>**`Install Service`** — добавляет любую стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаляет из служб стратегию и WinDivert
  - **`Check Status`** — показывает состояние обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — меняет режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима перезапустите стратегию.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — управляет обходом сервисов, перечисленных в `ipset-all.txt`.  
  Этот режим полезен при проверке ресурса, который открывается без zapret, но перестаёт работать вместе с ним.  
  В скобках выводится одно из текущих состояний:
    - `none` — IP-адреса не проверяются
    - `loaded` — для IP проверяется наличие в списке
    - `any` — фильтрация применяется к любому IP
  - **`Auto-Update Check`** — включает или отключает автоматическую проверку обновлений
  - **`Replace active fakes`** — заменяет указанный активный фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загружает из репозитория актуальную версию `ipset-all.txt`
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — ищет обновления
  - **`Run Diagnostics`** — проверяет распространённые причины, из-за которых zapret может не работать.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало подключаться
  - **`Run Tests`** — открывает средство проверки работоспособности стратегий:
    - `Standard tests` — тестирует сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` — проверяет DPI через разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неполадки

### После открытия скрипта `general*` ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe — процесс обхода, видимый на панели задач.  
Если он не открылся, ознакомьтесь с [#522](https://github.com/townfiscalspout/zapret-discord-youtube/issues/522)

### Не удалось подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из запустившегося Блокнота
  - В появившемся каталоге найдите `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts`; если похожие строки уже добавлялись, замените их
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения в `hosts` действительно сохранились

#### Работоспособность этого способа не гарантируется. Если он не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/townfiscalspout/tg-ws-proxy) либо любой публичный.

### Обход перестал работать или не запускается

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Конкретный вариант способен работать некоторое время, а затем перестать из-за обнаружения.
> В репозитории собрано много стратегий обхода. Если ни одна не подходит, создайте собственную: возьмите за основу один из представленных вариантов и измените его параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Выполните `service.bat` → `Run Diagnostics` и убедитесь, что диагностика не показывает ошибок

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов либо IP

- Переключитесь на другие стратегии, включая **`ALT`**, **`FAKE`** и остальные

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация приведена в [#765](https://github.com/townfiscalspout/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` → `Remove Services`
- Запустите `service.bat` → `Run Diagnostics`; устраните найденные ошибки и в конце выберите Y
- Удалите каталог с запретом
- Загрузите последнюю сборку (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/townfiscalspout/zapret-discord-youtube/releases)
- Щёлкните архив правой кнопкой мыши и откройте свойства. Если в правом нижнем углу есть пункт «Разблокировать», отметьте его, затем нажмите «Применить» и «ОК»
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы или специальные символы
- По очереди запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступность интернет-ресурсов. Если вариант не работает, закройте программу через значок замка на панели задач и перейдите к следующему
- Найдя рабочий вариант, добавьте его в автозапуск: `service.bat` → `Install Service` → выберите нужную стратегию

### При включённом запрете не запускается игра или приложение

- Убедитесь, что в `service.bat` для `Game Filter` указано **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert не исчезла

1. Откройте командную строку Windows через Win+R → `cmd` и определите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Выключите блокировщик рекламы: известно, что YouTube начал бороться с такими расширениями
- Переберите остальные стратегии, особенно если прежняя раньше работала, но затем перестала
- Дополнительные сведения есть в [#251](https://github.com/townfiscalspout/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён и настроен
- Сначала желательно найти стратегию, с которой открывается YouTube, и запустить именно её
- Перейдите в `service.bat` → `Run Diagnostics` и очистите там кэш Discord
- Снова запустите Discord и проверьте, помогло ли удаление кэша
- Откройте https://discord.com/app в браузере. Если браузерная версия работает, можно пользоваться ею
- Если Discord недоступен и в браузере, повторно проверьте все стратегии. Иногда один вариант открывает YouTube, но не подходит для Discord
- Дополнительная информация доступна в [#252](https://github.com/townfiscalspout/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/townfiscalspout/tg-ws-proxy)
- Другой вариант — бесплатные MTProto-прокси из интернета

### Не запускаются игры

Игр существует слишком много, поэтому исследовать и исправлять работу каждой из них невозможно.

Попробуйте наиболее универсальный порядок действий:
- обновите ipset через `service.bat`, затем активируйте `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учитывайте, что `ipset any` нарушает доступ ко многим сайтам, поэтому не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если рекомендации не помогли, создайте тему в разделе [Discussions](https://github.com/townfiscalspout/zapret-discord-youtube/discussions), а не в issues, и дождитесь советов других игроков.

## 🗒️Как добавить адреса других ресурсов

Чтобы расширить перечень адресов для обхода, внесите данные в соответствующие файлы:
- **`list-general-user.txt`** — домены; их поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключения IP-адресов и подсетей
  - Файлы вида **`*-user.txt`** создаются автоматически при первом запуске `zapret` либо `service.bat`
