> Антивирус может среагировать на WinDivert.

> WinDivert применяется как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусные продукты классифицируют файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляют их либо отправляют в карантин. Название такого обнаружения обязательно содержит `WinDivert` или выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Каталог с zapret можно добавить в исключения антивируса. Другой вариант — отключить обнаружение PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky для этого предусмотрен пункт «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно настраиваете исключения, рекомендуется добавить точечное исключение. Если не до конца понимаете последствия своих действий, предпочтительнее отключить обнаружение PUA.

## ⚙️Как начать работу

1. Настройте Безопасный DNS (Secure DNS)
    * Chrome: включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * Firefox: откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную введите URL. Например, подойдёт `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах системы — воспользуйтесь [этой инструкцией](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется именно такой способ
    * Владельцам роутеров Keenetic необходимо включить параметр «Транзит запросов». Если он отключён, при настройке и использовании Secure DNS на компьютере могут возникнуть проблемы

2. Загрузите архив в формате zip или rar со [страницы актуального релиза](https://github.com/townfiscalspout/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт «Разблокировать». При распаковке через 7-Zip или PeaZip этот этап не требуется

4. Извлеките архив в каталог, путь к которому не содержит кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы найти рабочую стратегию: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Чтобы добавить стратегию в автозапуск: **`service.bat`** → `Install Service` → *выберите подходящую стратегию*

## ℹ️Что делают основные файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной режим предназначен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящее для себя решение**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапускаемую стратегию и WinDivert
  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбор режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Эта функция пригодится при тестировании ресурса, который открывается без zapret, но не работает вместе с ним.  
  В скобках показывается активный режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — для IP выполняется проверка наличия в списке
    - `any` — под фильтрацию попадает любой IP
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуальной версии списка `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не работать.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало подключаться
  - **`Run Tests`** — запуск проверки работоспособности стратегий:
    - `Standard tests` — тестирование сайтов из файла `utils/targets.txt`
    - `DPI checkers` — проверка DPI через разных провайдеров, включая Cloudflare, Amazon и другие

## ☑️Частые вопросы и способы решения

### После открытия скрипта `general*` визуально ничего не происходит

При ручном запуске стратегии отдельным bat-файлом, а не через service, должен стартовать winws.exe. Значок программы обхода отображается на панели задач.  
Если winws.exe не появился, изучите [#522](https://github.com/townfiscalspout/zapret-discord-youtube/issues/522).

### Не удаётся подобрать работающую стратегию

- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`

    `netsh int ip reset all`

    `netsh winhttp reset proxy`

    `ipconfig /flushdns`

- После выполнения команд перезагрузите компьютер

### Не открывается веб-версия Telegram

Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:

- Скопируйте весь текст из автоматически открывшегося Блокнота
- В появившейся папке найдите `hosts` и откройте его текстовым редактором, запущенным от имени администратора
- Вставьте скопированный текст в конец `hosts`; если подобные строки уже добавлялись, замените их
- Сохраните файл и повторно проверьте подключение. Если результата нет, убедитесь, что изменения в `hosts` действительно сохранились

#### Работоспособность этого способа не гарантируется. Если он не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/townfiscalspout/tg-ws-proxy) либо любой публичный прокси.

### Обход не запускается или больше не помогает

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Конкретная конфигурация способна некоторое время работать, а затем перестать помогать после обнаружения.
> В этом репозитории собрано много вариантов обхода. Если ни один из них не подходит, создайте собственную стратегию: возьмите за основу одну из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` → `Run Diagnostics` и убедитесь, что диагностика не показывает ошибок

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Переберите остальные стратегии, в том числе **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация приведена в [#765](https://github.com/townfiscalspout/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?

- Сначала сохраните все самостоятельно добавленные данные и ресурсы
- Перезапустите устройство
- Выполните `service.bat` → `Remove Services`
- Затем откройте `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце нажмите Y
- Удалите каталог с zapret
- Загрузите свежую версию `zapret-discord-youtube-...` [со страницы релизов](https://github.com/townfiscalspout/zapret-discord-youtube/releases)
- Нажмите по архиву правой кнопкой мыши и откройте свойства. Если в правой нижней части окна есть пункт «Разблокировать», отметьте его, затем нажмите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступность интернет-ресурсов. Если очередной вариант не сработал, закройте программу через значок замка на панели задач и испытайте следующую стратегию
- Найденный рабочий вариант можно добавить в автозапуск: `service.bat` → `Install Service` → выберите нужную стратегию

### При включённом zapret перестаёт работать игра или приложение

- Убедитесь, что в `service.bat` для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Воспользуйтесь инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 запрашивает цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert остаётся в системе

1. Откройте командную строку Windows через Win+R → `cmd` и определите название службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, настроен ли [Secure DNS](#%EF%B8%8Fкак-начать-работу)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям
- Проверьте все остальные стратегии, особенно если ранее всё работало
- Дополнительные рекомендации находятся в [#251](https://github.com/townfiscalspout/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fкак-начать-работу) включён и настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её
- Перейдите в `service.bat` → `Run Diagnostics` и очистите кэш Discord
- Снова откройте приложение Discord и проверьте, помогла ли очистка
- Попробуйте веб-версию по адресу https://discord.com/app. Если она работает, можно временно пользоваться Discord в браузере
- Когда Discord не открывается даже в браузере, повторно переберите все стратегии. Иногда YouTube работает с определённой стратегией, а Discord — нет
- См. также [#252](https://github.com/townfiscalspout/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Запустите [tg-ws-proxy](https://github.com/townfiscalspout/tg-ws-proxy)
- Либо найдите и используйте бесплатные MTProto-прокси в интернете

### Возникают проблемы с играми

Игр существует слишком много, поэтому исследовать и исправлять работу каждой из них невозможно.

Наиболее универсальный порядок действий:

- через `service.bat` обновите ipset, после чего включите `Game Filter`
- если результата нет, дополнительно активируйте режим `ipset any`

Учитывайте, что `ipset any` способен нарушить доступ ко многим сайтам. Не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если предложенные действия не помогли, создайте новую тему в разделе [Discussions](https://github.com/townfiscalspout/zapret-discord-youtube/discussions), а не в issues, и дождитесь рекомендаций других игроков.

### Подходящего решения здесь нет

- Опишите проблему [в разделе issues](https://github.com/townfiscalspout/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить перечень адресов для обхода можно с помощью следующих файлов:

- **`list-general-user.txt`** — домены; их поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — исключения для доменов, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен из этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключения для IP-адресов и подсетей
  - Все файлы вида **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
